# Ubiquitous language

Use these names in code (types, functions, events, tables), tests and UI keys. UI text is English, translated to pt-BR.

| Term (code)       | Meaning                                                                                                                                                                                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Difficulty`      | `normal` \| `nightmare` \| `hell`. Fixed matchmaking filter, never relaxed                                                                                                                                                                                                                              |
| `Ladder`          | Combination of softcore/hardcore and ladder/non-ladder (`sc-ladder`, `sc-nonladder`, `hc-ladder`, `hc-nonladder`)                                                                                                                                                                                       |
| `Era`             | `lod` \| `rotw` \| `classic` — defines economy and available content                                                                                                                                                                                                                                    |
| `Region`          | Game region: `americas` \| `europe` \| `asia`. Fixed filter                                                                                                                                                                                                                                             |
| `Mode`            | `pvp` \| `leveling`                                                                                                                                                                                                                                                                                     |
| `Activity`        | Leveling: `baal`, `chaos`, `cows`, `tz`, `heralds`. PvP: `duel1v1`, `duel2v2`, `arena6`                                                                                                                                                                                                                 |
| `PvpRules`        | `gm` \| `bm`                                                                                                                                                                                                                                                                                            |
| `QueueTicket`     | An account's entry in a queue, with character and preferences                                                                                                                                                                                                                                           |
| `ReadyCheck`      | 1-minute window for every matched member to accept; on failure, those who accepted return to the top of the queue                                                                                                                                                                                       |
| `LobbyRoom`       | The platform room that corresponds to one game (or one leveling session of runs) in D2R                                                                                                                                                                                                                 |
| `Host`            | Member who creates the game in-game; in leveling, the teleporter                                                                                                                                                                                                                                        |
| `Run`             | One game inside a leveling session; each has its own name; none has a password                                                                                                                                                                                                                          |
| `GameName`        | `mm{activity}{difficulty}-{n}`, e.g. `mmbaalh-12` (ADR 017)                                                                                                                                                                                                                                             |
| `Observation`     | Fact read by the agent: `GAME_NAME_SEEN`, `PLAYER_JOINED_SEEN`, `PLAYER_LEFT_SEEN`, `SCREEN_CHANGED`, `ROUND_REPORTED`, `PLAYER_SLAIN_SEEN` (`PLAYER_JOINED_SEEN` and `PLAYER_LEFT_SEEN` carry one chat name that the API matches to a member and drops; only the member's join order is kept, ADR 036) |
| `Presence`        | Device state: online, game open, current screen                                                                                                                                                                                                                                                         |
| `Assignment`      | What the agent must look for now: room, run, expected name, members                                                                                                                                                                                                                                     |
| `PcState`         | Agent's adaptive state machine driving sensor intervals (e.g. `IDLE`, `IN_QUEUE`, `IN_ROOM_JOINING`, `IN_GAME`)                                                                                                                                                                                         |
| `RoomStage`       | `formed` → `awaiting_host` → `created` → `active` → `closed` \| `expired`                                                                                                                                                                                                                               |
| `JoinOrder`       | Order in which members joined; drives host succession and the moderation hierarchy                                                                                                                                                                                                                      |
| `ScoreReport`     | One side's report of a PvP round                                                                                                                                                                                                                                                                        |
| `Dispute`         | Divergent score after pairing both agents' observations; resolved by the room hierarchy with prints as evidence                                                                                                                                                                                         |
| `Rating`          | ELO for character × difficulty × season (K = 32)                                                                                                                                                                                                                                                        |
| `RuneRank`        | Named ELO band (Tal … Zod)                                                                                                                                                                                                                                                                              |
| `Season`          | Platform ranking season                                                                                                                                                                                                                                                                                 |
| `WalkOver` (W.O.) | Leaving an active duel counts as a loss (PvP only)                                                                                                                                                                                                                                                      |

## Proposed terms (not in code yet)

Added with FR-33…FR-36 on 2026-11-28, extended by the replanning of the same day (AD-180, AD-181, AD-183). The feature
spec confirms or renames them.

| Term (code)   | Meaning                                                                                                                                                                                                                                        |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `RoomList`    | The main screen: open rooms of the player's region with filters (origin, activity, difficulty, ladder, core, free slot, joinable by my character). F3                                                                                          |
| `OpenRoom`    | A `LobbyRoom` created from the list by its host (FR-37) and listed while it has a free slot. It has no ready check. F3                                                                                                                         |
| `RoomTag`     | A predefined label a host puts on an open room (e.g. teleporter hosting, leechers welcome). Never free text. F3                                                                                                                                |
| `QuickMatch`  | The button on the room list that creates a `QueueTicket` from the filters on the screen and the active character; the only path to a `ReadyCheck`. Replaces the matchmaking page. F3                                                           |
| `RoomOrigin`  | `platform` \| `spotted`. Where a listed room comes from. Shown on every row of the room list and never mixed: a platform room is a `LobbyRoom`; a spotted room is only a listing. In the contract from F3                                      |
| `SpottedRoom` | A regular D2R public game that some player's agent saw in the game-search screen. It has no members, host, ready check, generated name, score or ranking. F4                                                                                   |
| `Sighting`    | One agent's report of a spotted room: the game name as read and whatever else the screen showed (player count, difficulty when readable), plus the reporter's region, ladder and core. Never a character name. F4                              |
| `JoinAttempt` | What the agent reads when its player tries to join a game by name from the game-search screen: joined, the game does not exist (removes the room), the game is full (marks it full), or unrecognised (changes nothing). Read in F3, used in F4 |
